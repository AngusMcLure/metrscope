# Documentation

Use this directory for project documentation beyond the top-level README.

Suggested topics as the project develops:
- `design/`: architecture and design decisions.
- `methods/`: definitions, equations, calculation methods, and modelling assumptions.
- `user-guide/`: how to use and interpret the tool.
- `validation/`: test cases and comparisons against authoritative examples.

Keep documented behaviour aligned with what is actually implemented. Date and explain material assumptions, particularly where tax or benefit rules vary by financial year.
