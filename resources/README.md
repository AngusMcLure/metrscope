# Resources

Store supporting project assets that are not the main application source code.

Possible contents:
- `data/raw/`: source data retained as obtained, where licensing permits.
- `data/processed/`: reproducible derived datasets.
- `config/examples/`: example configuration files without secrets.
- `images/`: project diagrams and other static assets.

Document each resource's origin, licence or usage conditions, date/version, and any processing steps. Do not commit personal tax records, credentials, or other sensitive information. Avoid committing large or reproducible files without a clear reason.
