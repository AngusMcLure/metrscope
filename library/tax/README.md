# Tax reference topics

Use this area to organise source notes and rule summaries for Australian taxation.

Potential topics include:
- Personal income tax rates and thresholds
- Medicare levy and exemptions
- Tax offsets and rebates
- Deductions and assessable income where relevant to METR scenarios
- HELP and other income-contingent repayments, if in scope
- Superannuation taxes and contributions, if in scope

For each topic, record the relevant financial year, eligibility and residency assumptions, source references, calculation implications, edge cases, and validation examples. Do not assume that all listed topics will be included in the first version.
